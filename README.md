XOXO - Tic Tac Toe Game 

A simple Tic Tac Toe game built with Python and Tkinter. The game allows two players to play locally, with a random player chosen to start each round.

Features

- Two-player turn-based gameplay
- Winning tiles are highlighted in green
- Tie results highlight all tiles in yellow
- Reset button to start a new game
- Random starting player each round
- Simple Tkinter graphical interfac
